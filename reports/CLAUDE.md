# reports/ — 매일 일지와 주간 결산

## 역할
사람(사용자)이 읽는 글. `YYYY-MM-DD.md`(매일 일지), 일요일엔 `YYYY-MM-DD-week.md`(주간 결산). 저장소에만 둔다(블로그에 올리지 않는다, 사용자 결정 2026-10-20). 형식과 말투는 [docs/report-style.md](../docs/report-style.md)(잠정, 사용자가 읽고 고친다).

## 결정과 이유
- **숫자는 코드가 기록에서 채운다**(`python -m market.daily report` → `market/report.py`). 손으로 옮겨 쓰지 않는다 — 숫자가 하나라도 어긋나면 글 전체를 의심하게 된다(report-style 근거).
- 말로 쓰는 칸은 `[[채울 것: …]]` 자리로 남고, 매일 실행의 메인이 채운다. 채울 때 참고할 사실은 `<!-- 참고: … -->` 주석으로 붙는다. `python -m market.daily report --check`가 남은 자리를 센다.
- 계좌 표의 '누적'은 체결 기준 순투자(산 금액 + 수수료 − 판 금액 + 수수료)를 뺀 값이다. 평가 가격은 07:37에 알려진 마지막 끝난 종가다.

## 규칙
- 쓰는 것은 매일 예약 실행뿐이다(기록과 같은 이유: 두 군데서 엇갈리지 않게). 로컬·대화 세션은 이 폴더를 고치지 않는다.
- 이미 있는 일지를 뼈대로 덮지 않는다(`--force` 없이는 거절).
- 공개 저장소: 기사 본문 금지(요약 + 링크), 비밀값·개인 정보 금지. 끝에 "실제 돈이 아닌 가상 투자 실험이며 투자 권유가 아니다."

## 다른 폴더와의 관계
- 재료: `records/`(계좌·주문·체결·채점·돌아보기·조사), `places.toml`(볼 곳 이름). 만드는 코드: `market/report.py`.
