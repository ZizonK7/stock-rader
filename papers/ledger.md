# 이론 장부

이론마다 판이 어떻게 이어졌는지를 쌓는다. **덧붙이기만 한다**(지난 줄을 고치지 않고, 바뀌면 새 줄). 저자가 판 줄을 더하고, 심사·판정 칸은 학회장이 새 줄로 더한다. 양식은 [author.md](author.md) 2·4절. `papers/check.py`가 이 파일을 읽는다 — 표의 칸 순서를 바꾸지 않는다.
