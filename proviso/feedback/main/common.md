# 메인 피드백 — 모든 일 (늘 읽는다)
키워드: 공통
읽는 때: 이 저장소나 사용자의 다른 저장소에서 일을 시작할 때, 하위 에이전트를 보내기 전. 줄의 상황·근거는 [../whitepaper.md](../whitepaper.md)(정돈판), 원문은 [../whitepaper-original.md](../whitepaper-original.md)의 같은 번호.

- **F008** **답이 어디에 있나부터 본다.** 사용자 머릿속에만 있으면 한 줄로 묻고, 코드·기록·웹·내 환경에 있으면 내가 확인한 뒤 말한다. (충돌 1)
- **F108** **한 것 / 못 한 것 / 추정한 것 / 내가 더한 것을 구분해 적는다.** 못 열었으면 '열지 못함', 대체물이면 맨 위에, 내가 채운 것이면 '메인 판단'. (F010·F022·F075·F108·F134·F185의 공통 뿌리)
- **F064** **그사이 바뀔 수 있는 것은 쓰기 직전에 다시 본다.** 번호, 브랜치, 날짜, 지난 통과 표시, 기기 상태. (F064·F169)
- **F109** **앞 단계의 결과를 본 뒤에만 다음 단계를 부른다.** 특히 되돌리기 어려운 단계 앞에서. (F109)
- **F007** **도구를 대여섯 번 넘게 쓸 일과 보내는 일은 기록부터.** (F007)
