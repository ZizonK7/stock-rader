# stock-rader 장 시작 뒤 실행

너는 stock-rader의 **장 시작 뒤 실행**이다(한국 시간 09:05 시작). 사용자는 자리에 없고 질문할 수 없다. 할 일은 하나다: 오늘 아침 실행이 정한 목표 비중 그대로, 09:00에 팔린 돈으로 남은 사기를 지금 가격에 내는 코드 한 줄을 돌리고 그 기록을 main에 올린다. **새 판단을 하지 않는다**(조사·예측·비중 바꾸기·일지 고치기 없음).

## 0. 지킬 것
- **공개 저장소다.** 비밀값·개인 정보를 어디에도 적지 않는다.
- **기록은 덧붙이기만 한다.** `records/`의 줄을 손으로 고치거나 지우지 않는다. 기록은 `python -m market.daily open`만 쓴다.
- 이 실행에서 돌리지 않는 것: `python -m market.daily prepare`·`record`·`report`, `python -m market.prices update`, `python -m market.stocks add`, `python -m market.fit --write`, `python -m market.versions save`. 코드·문서·논리집·일지를 고치지 않는다.

## 1. 준비
1. stock-rader 저장소 폴더(보통 `/home/user/stock-rader`)로 가서 `git checkout main && git pull --ff-only origin main`. 저장소가 없으면 아무것도 하지 말고 마지막 보고에 그 사실만 적는다.
2. `TZ=Asia/Seoul date`로 시각을 본다. 09:01 전이면 09:01까지 기다린다. 한글이 깨지면 `export PYTHONIOENCODING=utf-8`.

## 2. 장 시작 뒤 단계
```
python -m market.daily open
```
하는 일(하루 한 번 — 두 번 돌려도 한 번만 쓴다): 계좌 넷마다 오늘 09:00에 치러진 주문을 장부에 넣고, 오늘 아침의 목표 비중으로 계획을 다시 돌려 팔린 돈으로 남은 사기를 지금 가격에 낸다. 계좌 줄은 새로 쓰지 않는다(오늘 일지의 표는 아침 판단 때 그대로이고, 이 단계의 거래는 내일 일지에 나온다).

출력에 따라:

| 출력 | 뜻 | 할 일 |
|---|---|---|
| `… 장 시작 뒤 단계(09:xx): order n, fill n, …` | 줄을 썼다 | 3으로 |
| `… 장 시작 뒤 단계(09:xx): 쓴 줄 없음` | 할 일이 없었다 | 커밋 없이 4로 |
| `판단 기록(run)이 없다` | 아침 실행이 아직 main에 올리지 않았다(또는 오늘 실행이 없었다) | 5분 뒤 `git pull --ff-only origin main` 하고 다시. **09:40까지** 그대로면 그만두고 4로 |
| `아직 장부에 안 들어왔다` | 오늘 09:00 가격을 아직 못 받았다(그 계좌는 아무것도 하지 않았다) | 3분 뒤 다시. **09:30까지** 그대로면 그때까지 쓰인 줄만 3으로(없으면 4로) |
| `이미 돌았다` | 오늘 이 단계가 이미 돌았다 | 아무것도 하지 않고 4로 |
| `아직 가상 증권사로 갈아타기 전이다` | 아침 실행이 오늘 옛 장부로 돌았다 | 아무것도 하지 않고 4로 |
| `가상 증권사 기록이 어긋나 있다`(종료 코드 1) | 아무것도 쓰이지 않았다 | 기록을 고치지 않는다. 그 출력과 `python -m market.broker status` 출력을 마지막 보고에 그대로 적고 끝낸다 |
| 그 밖의 오류·예외 | – | 다시 돌리지 않는다. `git status`로 `records/`가 바뀌었는지 보고, 바뀌었으면 `git checkout -- records`로 이 실행이 쓴 것을 버린 뒤(올리지 않은 줄만 버려진다) 출력을 마지막 보고에 적는다 |

- 출력의 `거절됨`은 증권사가 그 주문을 받지 않은 것이다(그 순간 가격을 못 받음, 돈이 모자람). 다시 내지 않는다 — 내일 아침 계획이 다시 낸다.

## 3. 검사와 커밋·push (줄을 썼을 때만)
```
python -m market.records check
```
- 통과하면:
```
git add records
git commit -m "장 시작 뒤 단계 <오늘>: <한 줄 — 예: 손 계좌 KODEX 200 3주 사기, 거절 0>"
git push origin HEAD:main
```
  커밋 메시지 끝에 빈 줄 다음 `Co-Authored-By: Claude <noreply@anthropic.com>`를 단다. `git diff --cached`에 `records/` 말고 다른 것이 있으면 커밋하지 않는다.
- push가 거절되면(아침 실행이 그사이 올림): `git pull --rebase origin main` 뒤 다시 push. 충돌이 나면 `git rebase --abort` 하고 `claude/stock-rader-open-<오늘>` 브랜치로 push한 뒤 마지막 보고에 적는다(사람이 합친다).
- 기록 검사가 실패하면: **기록 파일을 고치지 않는다.** `git checkout -- records`로 이 실행이 쓴 줄을 버리고(올리지 않은 줄만 버려진다 — 오늘 09:00 체결은 내일 아침 실행이 장부에 넣는다) 검사 출력을 마지막 보고에 그대로 적는다.

## 4. 마지막 보고 (이 실행의 마지막 메시지, 다섯 줄 안)
- 시작·끝 시각(한국 시간), `open` 출력의 첫 줄, 계좌별로 바로 치러진 것·거절된 것, 커밋·push 여부(커밋 해시), 다시 돌린 횟수와 까닭. 아무것도 하지 않았으면 그 까닭 한 줄.
