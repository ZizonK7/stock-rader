# docs/worklog/ — 작업 보고서

## 역할
작업 한 번마다 `YYYY-MM-DD-<주제>.md` 하나. 다음 작업자(메인 Claude, 사용자)가 무엇이 확인됐고 무엇이 안 됐는지 바로 알게 한다. PROVISO-Nesy `docs/worklog/`와 같은 방식이다.

## 양식
한 일 / 확인한 것(정확한 명령과 결과) / 확인 못 한 것 / 알려진 문제 / 다음 작업자에게 / 메인 판단 필요.

## 규칙
- 확인하지 않은 것은 "확인 못 함"으로 쓴다. 추측을 확인으로 쓰지 않는다.
- 쓴 뒤에 고치지 않는다(시간순 기록). 바뀐 결정은 루트 CLAUDE.md와 docs/design.md에 현재 기준으로 반영한다.
- 일상어로 쓰고 전문용어는 처음에 풀어 쓴다. 공개 저장소: 비밀값·개인 정보 금지.
