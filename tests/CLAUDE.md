# tests/ — 표준 라이브러리 unittest

## 역할
`python -m unittest discover -s tests -t .` (저장소 루트, 십여 초). 네트워크를 쓰지 않는다. 가짜 시세는 `fixtures.py`(정해진 씨앗의 무작위 일봉, 실제 시세가 아님).

| 파일 | 지키는 것 |
|---|---|
| `test_prices.py` | 받은 글 읽기, 끝난 일봉만, 덧붙이기만, 판단 시각에 알려진 줄만(view), 저장된 시세 파일의 순서·끝남 |
| `test_records.py` | 칸 검사, id·날짜 순서, git HEAD와 비교해 지난 줄이 바뀌거나 지워지면 실패 |
| `test_ledger.py` | 체결 날짜·가격, 수수료·올림, 1주·1e-8 단위, 현금 음수 금지, 가진 만큼만 팖, 시간 순서 정산 |
| `test_scoring.py` | 목표 종가, 방향(0.5는 말하지 않음), 확률 점수, 크기 적중, 기다림, 기저율 |
| `test_calc_fit.py` | 범위 합치기·2배 상한, 기준값 없으면 '모름', 결론을 바꾸는 조각만 설명, 맞추기가 FIT_UNTIL 뒤 시세를 안 봄(독 넣기), 방향과 범위가 어긋나는 효과를 세우지 않음 |
| `test_replay.py` | **뒤 시세에 독을 넣어도 그날까지의 기록이 같다**(미래 누설 없음), 재생 기록 칸, 마지막 날은 채점만 |
| `test_logic.py` | 논리집 장치(PROVISO 코어 + AUDIT): 손으로 바꾼 범위, 폭 상한, 이유 없는 숫자, 판단 전 값만 조건, 대상 이름, 조각 수 상한. PROVISO-Nesy가 없으면 건너뜀 |
| `test_research.py` | 조사 기록 칸(링크·결과 낱말·요약 길이), 돌아보기 까닭 낱말, 볼 곳 성적·새 곳 시도 몫, 질문이 조사 조각에서 나옴, 한 번만 세기, 조사 조각 상한(계산 조각과 따로)·모양, 버전 지문, 볼 곳 목록, 재생·실측 따로 판정, 쪼갠 조각이 조건을 더함, 더한 조건(`also`) 맞추기 |
| `test_daily.py` | **매일 실행 흉내 내기**(임시 폴더, 가짜 시세·조사·손 예측): 나흘 prepare → record → report(계좌 시작, 예측기 다섯, 코인 D+2·ETF D+3 정산, 판단 시각 뒤 체결, 채점·돌아보기 이어짐, 판단 때 가격, 일지 숫자와 채울 자리), 일요일 주간 결산, 빠진 날은 빈 날·지난 날짜 금지·같은 날 두 번 금지, 틀린 입력은 아무것도 안 씀, '잡음' 핑계 막기, 낡은 시세 대상 건너뛰기(ETF 휴장 구분), 정정은 덧붙임, 진짜 폴더에서 `--day` 금지 |

## 규칙
- 네트워크·실제 시세 받기를 하지 않는다(받기는 파싱만 시험). 저장된 실제 시세를 읽는 시험은 파일이 없으면 건너뛴다.
- 재생 기간(2026-07-01~) 실제 시세로 결과를 내는 시험은 만들지 않는다(홀드아웃을 시험 코드가 엿보지 않게).
- 진짜 기록 폴더(`records/*.jsonl`)를 쓰는 시험은 만들지 않는다. 매일 실행 시험은 임시 폴더(`daily.copy_for_simulation`)에서.
- 장치를 지키는 시험을 지워서 통과시키지 않는다.

## 다른 폴더와의 관계
`market/`를 시험한다. `test_logic.py`·`test_research.py`는 `knowledge.toml`·`places.toml`·`versions/`와 PROVISO 코어를 읽는다.
